## Brand & Style

This design system establishes a high-tech, precision-engineered aesthetic tailored for advanced engineering documentation, technical architectures, and enterprise point-of-sale platforms. The visual character channels deep cybernetic navigation systems, computational networks, and mission-critical telemetry consoles.

The core visual language blends **Dark Technical Minimalism** with **Refined Glassmorphism** and subtle **Cyan Neon Laser Accents**. Background surfaces adopt deep obsidian navy and midnight slate tones, illuminated by translucent architectural glass panels and razor-sharp cyan edge lighting inspired by nodal vector networks. 

The emotional response should evoke technical mastery, unwavering stability, precision, and modern software craft. Interfaces prioritize information density, code readability, API endpoint exploration, and structural clarity without sacrificing atmospheric depth.

## Colors

The palette draws directly from luminous nodal graphs embedded within abyssal deep space:

- **Primary (`#00B4D8`)**: Vibrant electric cyan used for primary active states, focal action elements, terminal highlights, and primary key metrics.
- **Secondary (`#48CAE4`)**: Luminous laser cyan used for glowing border gradients, interactive hover states, badges, and code accents.
- **Tertiary (`#0077B6`)**: Rich cobalt blue anchoring secondary controls, active tab indicators, and subtle illuminated surface backings.
- **Neutral (`#0A1128` & `#0D1B2A`)**: Abyssal midnight and deep cyber slate formulating the base canvas, sidebar surfaces, and structural backdrop.

### Surface Tones & Tokens
- **Canvas Base**: `#060A17` (Deepest Void)
- **Surface Elevation 1**: `#0A1128` with 80% opacity backdrop blur
- **Surface Elevation 2**: `#0E1B38` with 60% opacity backdrop blur
- **Surface Elevation 3 / Popovers**: `#14254B`
- **Text Primary**: `#F8FAFC` (Crisp Signal White)
- **Text Secondary**: `#94A3B8` (Slate Silver)
- **Text Muted**: `#475569` (Dark Steel)
- **Border / Neon Trace**: `rgba(0, 180, 216, 0.22)` with hover scaling to `rgba(72, 202, 228, 0.65)`

## Typography

The typographic system pairs three specialized typefaces:
- **Headlines (`Space Grotesk`)**: Technical, geometric, and architectural. Provides bold programmatic authority for top-level headers, showcase titles, and section splits.
- **Body & Prose (`Geist`)**: Ultra-clean, neutral developer-grade grotesque offering maximum legibility across complex technical descriptions, architecture write-ups, and data tables.
- **Labels, Telemetry & Code (`JetBrains Mono`)**: Monospaced clarity for syntax blocks, .NET namespaces, API routes, parameter badges, and hardware status tokens.

## Layout & Spacing

The portal is structured on a 12-column dynamic engineering grid:
- **Desktop (1280px+)**: 12 columns with a fixed 280px left documentation tree, an 800px central prose/playground container, and a 240px right "On This Page" nodal navigation panel. `gutter-lg` is 2rem; main canvas margins are 2rem.
- **Tablet (768px - 1279px)**: 8 columns with collateral drawer navigation and sticky secondary breadcrumbs. `gutter` is 1.5rem; margins are 1.5rem.
- **Mobile (< 768px)**: 4 columns, single-column full flow with off-canvas sheet navigation and compact spacing (`margin-mobile` of 1rem; `gutter-sm` of 1rem).

The spacing cadence enforces geometric rhythm through standardized multiples of 4px/8px, prioritizing compact density for technical telemetry and comfortable breathing room for architectural prose.

## Elevation & Depth

Visual depth is achieved through layered translucent planes, geometric wireframe borders, and luminous cyan photon glows:

1. **Surface 0 (Basebed)**: Deepest void `#060A17`, optionally patterned with faint 32px nodal vector grid lines in `rgba(0, 180, 216, 0.04)`.
2. **Surface 1 (Structural Shells & Sidebars)**: `#0A1128` at 85% opacity with `backdrop-filter: blur(16px)` and a 1px border of `rgba(72, 202, 228, 0.12)`.
3. **Surface 2 (Glassmorphic Cards & Code Frames)**: Gradient fill from `rgba(14, 27, 56, 0.7)` to `rgba(10, 17, 40, 0.45)` with `backdrop-filter: blur(20px)` and perimeter stroke `rgba(0, 180, 216, 0.2)`.
4. **Surface 3 (Overlays, Tooltips & Dropdowns)**: `#14254B` with ambient neon drop-shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6), 0 0 16px -2px rgba(0, 180, 216, 0.25)`.
5. **Active Glow State**: Interactive focus states leverage double-layer box shadows: `0 0 0 1px #00B4D8, 0 0 18px 2px rgba(0, 180, 216, 0.35)`.

## Shapes

The design system enforces a precision, low-radius geometric silhouette (`roundedness: 1` / Soft):
- **Base Components (Buttons, Chips, Inputs, Badges)**: 4px (`0.25rem`) corner radius. This gives an intentional, high-precision industrial CAD instrumentation feel.
- **Containers & Glass Panels (`rounded-lg`)**: 8px (`0.5rem`) corner radius.
- **Modals & Showcase Viewports (`rounded-xl`)**: 12px (`0.75rem`) corner radius.
- **Avatars & Pulsing Status Nodes**: Full circular boundary (`rounded-full`), signaling active threads and operational states.

## Components

### Buttons
- **Primary Cyber Action**: Solid `#00B4D8` background with dark `#060A17` bold typography, `border: 1px solid #48CAE4`. Hover generates a radiant cyan bloom `box-shadow: 0 0 20px rgba(0, 180, 216, 0.5)`.
- **Secondary Ghost / Outline**: Background `rgba(14, 27, 56, 0.5)` with `border: 1px solid rgba(0, 180, 216, 0.3)` and `#F8FAFC` label. Hover transforms border to bright cyan with `rgba(0, 180, 216, 0.1)` fill.
- **Monospace Icon Tool**: 36x36px square button with 4px radius, displaying inline SVG glyphs in slate `#94A3B8`, brightening to `#48CAE4` on hover.

### Chips & Badges
- **Architecture / Tech Tags**: JetBrains Mono typography, 20px height, 4px radius. Base background `rgba(0, 119, 182, 0.18)`, border `1px solid rgba(0, 180, 216, 0.25)`, text `#48CAE4`.
- **Telemetry Live Pill**: Contains a small 6px circular green/cyan beacon with an animated ping ring indicating live service or POS driver sync.

### Code Blocks & Architecture Walkthroughs
- Multi-file tabs embedded atop syntax blocks with dark acrylic backdrops (`#070D1F`).
- Integrated one-click copy button, language indicator badge, line-number dividers in `rgba(148, 163, 184, 0.2)`, and highlighted line gradients tinted with `rgba(0, 180, 216, 0.08)`.

### Cards & Architecture Panels
- Frosted dark slate surface (`rgba(10, 17, 40, 0.75)`), 1px gradient hairline border (`linear-gradient(135deg, rgba(72, 202, 228, 0.4), rgba(0, 119, 182, 0.05))`).
- Top-right corner accented with an engineering coordinate indicator or subtle nodal connection pin.

### Inputs & Search
- Quick-filter and documentation search inputs feature dark inset containers (`#080E21`), subtle cyan borders on focus, and an explicit keyboard shortcut chip (`⌘K` or `Ctrl+K`) styled in JetBrains Mono.

### Checkboxes, Radios & Switches
- Checkboxes: 16x16px squares with 3px radius. Checked state fills with `#00B4D8` and presents a high-contrast dark `#060A17` checkmark.
- Toggles: Cyber-switch style with rectangular rail and glowing thumb indicator displaying system state changes without delay.
